# MoraJaiDLE

MoraJaiDLE is a daily Mora Jai Box game inspired by the game Blue Prince as well as [BluePrintle](https://blueprintle.org/) and [Joric's Mora Jai Box solver](https://joric.github.io/blueprince/) -> If you're just looking for help with the ingame mora jai boxes, check this out

## Available Modes

- Edit
- Solve
- Daily

All puzzles generated should have a valid solution


### Disclaimer
This is still a work in progress so please report any issues [here](https://github.com/jorlando989/mora-jai-sim/issues)
